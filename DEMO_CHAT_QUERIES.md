**To clear the chat conversation:**
- Click the **"Clear"** button in the top-right corner of the chat panel (appears once you have messages)
- This will reset the entire chat session and start fresh

## Demo Flow Best Practices

### Recommended Demo Sequence:

1. **Start Clean**: Use "Clear" button to reset chat
2. **Select ODIN Scenario**: Choose "Bagansait" from scenario selector
3. **Opening Query**: "Provide a full PMESII assessment for Bagansait"
4. **Follow-up Deep Dive**: "What are the top 3 military threats in this region?"
5. **Location Context**: Click map to set new AOI, then ask: "Assess threats for current AOI"
6. **Risk Analysis**: "What force protection measures are recommended?"
7. **Comparative Analysis**: "How does this compare to South Torbia?"

### Tips for Effective Demos:

✅ **DO:**
- Start with ODIN scenario selection for context
- Use specific location names (Bagansait, Dhaka, etc.)
- Ask for PMESII-specific assessments
- Request risk levels and confidence scores
- Show map integration by changing AOI between queries

❌ **DON'T:**
- Ask overly generic questions without context
- Forget to show the ODIN attribution badges
- Skip clearing chat between different scenario demos
- Ignore the risk scoring and confidence levels in responses

## Expected Response Components

Each tactical query should produce:

1. **Main Analysis**: Comprehensive text response
2. **Risk Badge**: Visual indicator (LOW/MEDIUM/HIGH/CRITICAL)
3. **ODIN Attribution**: "ODIN DATE: [Country]" badge showing data source
4. **Key Findings**: Structured insights (in some responses)
5. **Recommendations**: Actionable guidance (in threat assessments)
