# GuideRight Intelligence Assistant - Analyst Demo Walkthrough

## Overview
GuideRight is a tactical intelligence platform integrating ODIN DATE scenarios, multimodal analysis, PMESII framework assessment, and AI-powered threat evaluation for USSOCOM operations.

## System Architecture
- **ODIN Integration**: Real-time access to Decisive Action Training Environment (DATE) scenarios
- **Intelligence Framework**: PMESII (Political, Military, Economic, Social, Information, Infrastructure) analysis
- **AI Assistant**: OpenAI-powered tactical analysis with confidence scoring
- **Mapping System**: Google Maps/Leaflet with AOI selection and route planning
- **Multi-source Fusion**: Dempster-Shafer confidence aggregation

## Demo Scenario Walkthroughs

### Scenario 1: Bagansait Political Instability Assessment
**Duration**: 5-7 minutes  
**Objective**: Demonstrate ODIN integration and PMESII analysis for emerging threats

#### Steps:
1. **Initial Setup** (30 sec)
   - Open GuideRight dashboard
   - Map centered on Indo-Pacific region
   - Note: Clean interface, professional military aesthetic

2. **ODIN Scenario Selection** (30 sec)
   - Click ODIN scenario dropdown (top-left of map)
   - Select "Bagansait" from Indo-Pacific region
   - System loads Bagansait DATE scenario

3. **Intelligence Query** (1 min)
   - Expand Chat Assistant (bottom-left panel)
   - Query: *"What is the current political situation in Bagansait?"*
   - Watch AI process with ODIN context
   - Note ODIN DATE attribution badge on response
   - Risk level badge displays threat assessment

4. **PMESII Deep Dive** (2 min)
   - Click Intelligence button (bottom nav)
   - Navigate to PMESII tab
   - Review six factors:
     - **Political**: Government stability, regional relations
     - **Military**: Force capabilities, threat assessment
     - **Economic**: Infrastructure, trade vulnerabilities
     - **Social**: Demographics, cultural tensions
     - **Information**: Media landscape, narrative control
     - **Infrastructure**: Critical systems, dependencies
   - Each factor shows confidence scores from multiple sources

5. **Map Visualization** (1 min)
   - Return to Map view
   - AOI (Area of Interest) selector for Bagansait capital
   - Toggle satellite/terrain views
   - Note: Real-time risk overlay (if available)

6. **Follow-up Analysis** (1 min)
   - Chat query: *"Analyze military threats to US forces in Bagansait"*
   - AI provides tactical assessment
   - Cross-reference with PMESII Military factor
   - Export analysis for reporting

**Key Talking Points**:
- ODIN provides realistic, comprehensive training scenarios
- PMESII framework ensures holistic threat assessment
- AI synthesizes multiple intelligence sources
- Confidence scoring prevents over-reliance on uncertain data

## Demo Tips for Success

### Before Demo
1. **Pre-load Scenarios**: Cache ODIN data for smooth transitions
2. **Check API Keys**: Ensure OpenAI quota available
3. **Test Queries**: Prepare specific questions that showcase capabilities
4. **Clear History**: Start with clean chat for clarity

### During Demo
1. **Emphasize Realism**: ODIN provides real military training scenarios
2. **Show Integration**: Demonstrate how PMESII, AI, and mapping work together
3. **Highlight Confidence**: Point out confidence scores - critical for Intel work
4. **Focus on Workflow**: Not just features, but actual analyst operations

### Key Differentiators
- **ODIN Integration**: Only system with direct DATE scenario access
- **PMESII Framework**: Structured intelligence methodology
- **AI Enhancement**: Not replacing analysts, augmenting their capabilities
- **Confidence Scoring**: Transparent about data reliability

### Common Questions

**Q: How current is the ODIN data?**  
A: ODIN DATE scenarios are regularly updated by TRADOC G-2. GuideRight pulls latest versions.

**Q: Can this work with classified data?**  
A: Current version is unclassified. Architecture supports secure enclaves for classified operations.

**Q: What if AI is wrong?**  
A: Confidence scores indicate reliability. Analysts always verify. AI augments, doesn't replace judgment.

**Q: Does this replace current Intel systems?**  
A: Complementary tool. Integrates with existing workflows, doesn't replace established platforms.

## Troubleshooting

### If OpenAI Quota Exceeded
- System automatically falls back to mock responses
- Demonstrates UI/UX even without live AI
- Note: Production uses dedicated API instances

### If Map Doesn't Load
- Check Google Maps API key
- Fallback to Leaflet/OpenStreetMap
- All features functional with either provider

### If ODIN Scenario Fails
- Verify network connectivity
- Check ODIN service status
- Fallback: Use cached scenario data
