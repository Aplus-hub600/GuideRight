# 🚀 Build me this app: GuideRight — A Multimodal LLM-Powered Tactical Assistant (MVP)

## TL;DR

Create a **full-stack TypeScript** app that runs in Replit with:

* **Frontend:** React + Vite + Tailwind + shadcn/ui + Leaflet map + i18next.
* **Backend:** Node + Express + Zod + simple in-memory store.
* **Multimodal:** chat (text), mic input (speech-to-text), TTS playback, image/video file drop (stub analysis).
* **Analytics core:** PMESII tagging, risk scoring, and a **Dempster–Shafer (DS) confidence combiner** across data sources.
* **Mock data providers:** Fraym, Seerist, Sprinklr, News, Social, Weather, Infra.
* **LLM adapter:** single interface with a no-key “mock model” + optional OpenAI (env-gated).
* **Everything runs locally with mock data**; external APIs are optional via `.env`.

## 0) Project Name

`guideright-mvp`

## 1) Top-Level Goals / User Story

As a **USSOCOM analyst** or **deployed operator**, I can:

1. Type or speak a question about any **AOI (area of interest)** (place or lat/lng).
2. See a **map** of the AOI, plus **fused intel panels** (Population, Culture/Religion, Economy, Infrastructure/Comms, History of Unrest, Current Triggers).
3. Get a **chat response** that references sources and includes a **confidence score** derived via **Dempster–Shafer** from the underlying data layers.
4. Upload an **image or short video** (mock-analyzed) to enrich situational context.
5. See **risk heat** and a suggested **movement plan** (simple route + rationale).
6. Switch **language** (UI + answers) for **multilingual ops**.

## 4) Core Domain & Types (server/types/domain.ts)

Create Zod/TS interfaces for:

* `AOI` `{ name?: string; lat: number; lng: number; radiusKm?: number }`
* `PMESIICategory` union: `"Political"|"Military"|"Economic"|"Social"|"Information"|"Infrastructure"`
* `IntelItem` `{ id:string; source:"Fraym"|"Seerist"|"Sprinklr"|"News"|"Social"|"Weather"|"Infra"; pmesii:PMESIICategory[]; text:string; time?:string; quality: number /*0..1*/ }`
* `FusedSnapshot` `{ aoi: AOI; items: IntelItem[] }`
* `DSBelief` `{ belief: number; disbelief: number; uncertainty: number }`
* `Answer` `{ text:string; language:string; citations:string[]; pmesiiCoverage:Record<PMESIICategory,number>; riskScore:number; confidence:DSBelief }`
* `MovementPlan` `{ route: Array<{lat:number;lng:number} >; rationale: string }`

---

## 5) Backend Endpoints (Express)

1. `POST /api/ingest/aoi`

   * Body: `{ aoi: AOI }`
   * Loads mock provider data for nearest AOI file (simple nearest-neighbor on lat/lng). Returns `FusedSnapshot`.
2. `POST /api/query`

   * Body: `{ aoi: AOI, question: string, language?: string, mediaContextIds?: string[] }`
   * Pipeline: (a) get fused snapshot → (b) PMESII tag & summarize → (c) call LLM adapter (mock/OpenAI) to craft answer → (d) compute DS confidence from provider items’ `quality` and per-source weights → (e) return `Answer`.
3. `POST /api/risk`

   * Body: `{ aoi: AOI }`
   * Returns `{ riskScore:number, factors: Array<{pmesii:PMESIICategory; score:number; note:string}> }`.
4. `POST /api/confidence`

   * Body: `{ items: IntelItem[] }`
   * Returns `{ confidence: DSBelief }` combining evidence via DS rule.
5. `POST /api/media/analyze`

   * Accepts image/video upload (use `multer`). Returns mock intel items extracted (tagged + quality).
6. `GET /api/mock/aoi`

   * Returns a list of available mock AOIs and their centroids.

**Validation:** Use Zod on each route.

---

## 6) Services (server/src/services)

* **`ds.ts`**: Implement basic Dempster–Shafer combine:

  * Define per-source belief masses `m_source = { belief: q, disbelief: 1-q-u, uncertainty: u }` with configurable `u`.
  * Combine two masses with Dempster’s rule; iterate over all items.
  * Output final `{ belief, disbelief, uncertainty }`.
* **`pmesii.ts`**: Simple keyword/regex & embedding-stub tagging to map intel to PMESII categories; return coverage histogram.
* **`risk.ts`**: Weighted sum over risk factors:

  * Latent “fuel” (demographics, poverty/unemployment proxies),
  * “Triggers” (recent protests, inflammatory events from news/social),
  * Weather/infra disruptions.
  * Normalize to 0–100.
* **`fuse.ts`**: Fuse providers → remove dupes, score quality, sort by recency.
* **`llm.ts`**:

  * If `OPENAI_API_KEY` present, use `gpt-4o-mini` (or similar) with system prompt that requires: (a) cite sources, (b) list PMESII coverage, (c) keep answers concise for ops, (d) return JSON fields if asked.
  * Else use **mock LLM** that templates an answer from fused intel.
* **`translate.ts`**:

  * If `TRANSLATE_BASE_URL` present (e.g., LibreTranslate), call it; else fallback to identity (English).
* **`geocode.ts`**:

  * If `MAPBOX_TOKEN` present, allow forward geocode; otherwise accept only lat/lng inputs.
* **`media.ts`**:

  * Stub “vision” extraction: return a couple of `IntelItem`s with `source:"Social"` and reasonable `pmesii` tags.

## 8) PMESII & Risk Model (initial rules)

* **PMESII tagging heuristics:**

  * Political: “election”, “governor”, “corruption”, “policy”, “curfew”.
  * Military: “checkpoint”, “militia”, “IED”, “patrol”, “airstrike”.
  * Economic: “market”, “unemployment”, “inflation”, “supply chain”.
  * Social: “protest”, “ethnic”, “religion”, “festival”, “norms”.
  * Information: “internet blackout”, “SMS outage”, “rumor”, “misinfo”, “radio”.
  * Infrastructure: “bridge”, “power grid”, “cell tower”, “hospital”, “road”.
* **Risk score (0–100):**
  `risk = clamp( 40*fuel + 45*triggers + 15*disruption )` with each factor in 0..1.
  Fuel from econ + social stresses; Triggers from recent news/social items; Disruption from weather/infra items. Include a small decay by item age.

## 9) Confidence via Dempster–Shafer (MVP)

* **Per-source priors** (editable in `server/src/services/ds.ts`):

  * Fraym: q=0.80, u=0.10
  * Seerist: q=0.75, u=0.12
  * Sprinklr: q=0.60, u=0.20
  * News: q=0.70, u=0.15
  * Social: q=0.50, u=0.30
  * Weather: q=0.85, u=0.10
  * Infra: q=0.78, u=0.12
* Combine masses of items **relevant to the answer** and return `{belief, disbelief, uncertainty}`; surface as **Confidence**.
