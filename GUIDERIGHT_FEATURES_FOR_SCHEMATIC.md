## 🛠️ Technical Architecture

### Frontend Stack
- **React 18 + TypeScript**: Type-safe component development
- **Vite**: Lightning-fast development and optimized production builds
- **TailwindCSS + shadcn/ui**: Professional component library
- **TanStack Query**: Efficient server state management
- **i18next**: Internationalization framework
- **Framer Motion**: Smooth animations and transitions

### Backend Stack
- **Node.js + Express**: REST API server
- **TypeScript**: Full-stack type safety
- **Drizzle ORM**: Type-safe database operations
- **PostgreSQL (Neon)**: Serverless production database
- **Multer**: Multipart file upload handling
- **Zod**: Runtime schema validation

### AI & Intelligence
- **Google Gemini 2.5 Flash Lite**: Primary AI engine with Maps grounding
- **OpenAI GPT-4**: Secondary tactical analysis
- **Gemini 2.5 Pro**: Advanced PMESII analysis
- **Custom ODIN Mock Data**: 15+ country intelligence scenarios
- **Dempster-Shafer Engine**: Multi-source confidence fusion

### APIs & Services
- **Google Maps JavaScript API**: Primary mapping service
- **Leaflet + OpenStreetMap**: Fallback mapping solution
- **Web Speech API**: Voice input/output
- **EXIF Reader**: Image metadata extraction
